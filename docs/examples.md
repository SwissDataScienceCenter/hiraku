# Examples

The examples are runnable projects that show the same Hiraku lifecycle with
different tracking backends.

## Heart Disease

The recommended first walkthrough. It bundles the processed dataset and uses
CSV, so it works offline:

- [Your first experiment](first-experiment.md)
- [Heart Disease project README](https://github.com/SwissDataScienceCenter/hiraku/tree/main/examples/heart-disease)

- [Interactive Python notebook](https://github.com/SwissDataScienceCenter/hiraku/blob/main/examples/iris-wandb/interactive.ipynb)
