sequence-level-dedup — hypothesis and decision

Contamination in this project is structural — a consequence of indexing every frame of every pass — so deduplicating to one representative per pass per place before retrieval removes it without any per-candidate exclusion rule, and therefore without the recall trade-off both existing nodes pay.

Why it holds. Requiring consistent two-view geometry rejects retrieved pairs that have no plausible geometric relationship. Against retrieval-baseline, precision moves 0.709 → 0.961 for 0.023 of recall, so the comparison establishes that the baseline's errors were predominantly geometrically inconsistent rather than genuinely ambiguous.

What it does not establish. The threshold was fixed at 3.0 px and never varied here; ransac-threshold-sweep looked and came back inconclusive, so how much of the margin depends on that specific value is unknown. The number is also an aggregate — it says nothing about whether particular conditions still fail, and vggt-pose-consistency exists because sparse-correspondence failures are suspected to persist inside it.
