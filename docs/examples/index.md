# Examples

The examples are runnable projects that show the same Hiraku lifecycle with
different tracking backends.

- [Heart Disease Example](heart-disease/README.md) - The recommended first walkthrough. It bundles the processed dataset and uses
CSV for tracking.
- [Iris with Weights & Biases](iris-wandb/README.md) - A simple example using the Iris dataset and Weights & Biases for tracking.
