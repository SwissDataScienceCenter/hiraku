# Examples

Run `hiraku example list` to see example names, titles, and descriptions.
Use `hiraku example create` to copy an example into a local directory. Add
`--with-results` to include records and runs. The command also sets
up the same agent skills and MCP configuration as `hiraku init`.

| Example | Description |
| --- | --- |
| [Digits](digits/README.md) | Track model runs and metrics with MLflow. |
