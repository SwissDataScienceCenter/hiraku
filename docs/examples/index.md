# Examples

The examples are runnable projects that show the Hiraku lifecycle with
different datasets and tracking backends.

- [Start from scratch](minimal/README.md) — initialize a minimal project with a
  ready-to-run local evaluation script.
- [Heart Disease](heart-disease/README.md) — the recommended first walkthrough. It bundles the processed dataset and uses CSV tracking.
- [Iris with Weights & Biases](iris-wandb/README.md) — a small classification example using the Iris dataset and W&amp;B.
- [Digits with MLflow](digits-mlflow/README.md) — compare regularization strengths while logging learning curves to MLflow.
- [Autoresearch](autoresearch/README.md) — run a pinned autonomous research loop with a CPU-only workflow check.
