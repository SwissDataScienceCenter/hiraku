# Grill questions

Ask only what the records and code do not answer, one at a time, each with a
recommended answer.

1. **Purpose.** Which decision will the result inform? Is a record needed at
   all, or is this a note?
2. **Hypothesis.** What do you expect to change, and why? Phrase it so a run
   could contradict it.
3. **Baseline.** Which sibling is the baseline, and what differs from it?
4. **Criterion.** Which root metric decides, in which direction, and what
   margin counts as support, refutation, or inconclusive (e.g. against the seed
   standard error)?
5. **Comparability.** Which split, seeds, budget, and protocol must match?
6. **Cheapest test.** Can an existing entrypoint or argument test it without a
   code change?
7. **Limits.** Compute, time, or credentials, and what is out of scope.
