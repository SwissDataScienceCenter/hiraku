# Hiraku

Hiraku connects research goals, records, source code, execution, evidence, and conclusions.

The coding harness owns reasoning, repository inspection, code editing, looping, and user interaction. Hiraku owns authoritative research state, validation, commits, launches, attribution, and recorded conclusions.

Use Hiraku MCP for authoritative research state and consequential operations when available. Do not directly edit Hiraku records or run metadata to bypass it.

Follow the user's scope and preserve existing user work and provenance.

For a named workflow, read and follow the corresponding Hiraku Program. Use `interactive` for guided step-by-step work and `autoresearch` for bounded autonomous experimentation.

Treat Hiraku validation failures as constraints to diagnose, not obstacles to bypass.
