# Bounded autonomous research program

Before starting, obtain human approval for the task goal and scope, evaluation protocol, permitted commands, resource bounds, permissions, and stopping conditions. Record these boundaries in this file or `task.md`.

Within the approved boundaries, the agent may update the plan, create experiment records, implement and commit experiments, bind source commits, launch declared entrypoints, inspect and compare results, update findings, accept or reject changes, and choose the next in-scope iteration.

Pause before changing the goal, scope, evaluation protocol, permitted commands, resource bounds, permissions, or stopping conditions. Never merge into a protected branch without explicit human approval. Stop when an approved stopping condition is met and expose all task, experiment, Git, launch, and run artifacts for review. Treat this program as workflow guidance, not as a security boundary.
