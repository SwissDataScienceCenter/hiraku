# Autoresearch overlay

This example adds Hiraku's task, program, CPU mock, and run dispatcher to an
existing checkout of [`karpathy/autoresearch`](https://github.com/karpathy/autoresearch).

From the upstream repository root, run:

```bash
hiraku init --example autoresearch
```

See `docs/examples/autoresearch/README.md` in the Hiraku repository for the
complete setup and usage guide.
