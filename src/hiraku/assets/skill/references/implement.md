# Implement an experiment plan

1. Read `experiment.md`, `policy.md`, and `launch.yml`; confirm the checked-out branch matches.
2. In guided mode, require explicit approval of the plan before editing code.
3. Keep changes inside the documented scope and preserve the evaluation protocol.
4. Validate changes proportionally, but do not launch an experiment without the policy-required
   approval.
5. In guided mode, present the proposed diff and obtain approval before committing.
6. Update documentation only with evidence actually produced by code or tracked runs.
