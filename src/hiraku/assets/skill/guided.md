# Guided workflow

Obtain explicit user approval before each of these actions:

1. creating an Experiment;
2. editing Experiment source;
3. committing source;
4. launching a Run;
5. concluding or abandoning an Experiment.

Use `hiraku goal show`, `hiraku experiment show`, `hiraku runs --json`, and `hiraku experiment
tree` to present evidence. Call CLI commands for lifecycle changes. Do not update SQLite directly.
