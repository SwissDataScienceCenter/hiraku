# Guided experiment policy

The data scientist directs this experiment and reviews each checkpoint.

## Required checkpoints

Obtain explicit approval in the active conversation before:

1. implementing or materially changing the approved plan;
2. creating a Git commit;
3. launching an experiment entrypoint;
4. writing findings or conclusions; and
5. changing this policy, the experiment scope, or the evaluation protocol.

Never merge into a protected branch without explicit human approval.

This policy guides agent behavior. It is not a security boundary; repository protections,
sandboxing, credentials, and execution infrastructure remain authoritative.
